# Seasonal Changes 1.0.0

Grades 6–8. TEKS 6.9A is grade 6 core; grades 7–8 revisit the mechanism and extend to heat storage. NGSS MS-ESS1-1 seasons component only; the worksheet supplies student model development. Lunar phases and eclipses are outside this lab.

Serve the site root over HTTP and open seasonal-changes/. Reuses ../kit/ unchanged. Controls, evidence tables, five checks and ten vocabulary terms are available in EN/ES. Spanish is draft pending native-speaking science educator review. Public flashcards: flashcards.html (English, Spanish, bilingual; print/Save as PDF, CSV, offline HTML).

Physics: circular orbit; solar constant 1361 W/m²; exact sunrise geometry and daily horizontal top-of-atmosphere solar input; idealized equal quarters. Temperature is an illustrative periodic anomaly relative to each location’s own annual mean, using 18/60-day response times. It is not a weather forecast or calibrated climate dataset. No random sunlight noise. Seeds choose repeatable hemisphere challenge settings only.
