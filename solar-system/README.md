# Solar System in Motion 1.0.0

Sciesmic Labs science simulation for grades 6–8; grade 7 focus. Explore eight planetary orbits, compare distance and period, then investigate solar gravity with an imaginary planet. Includes EN and draft es-MX, five explained checks, contextual definitions and vocabulary print/CSV/offline-HTML tools.

Run the parent site root over HTTP. No build step, remote libraries or credentials are needed. Open `solar-system/`. `model.js` is DOM-free. Initial phase seed 42 gives a reproducible illustration, not present-day sky positions. Scientific notes and original-source links are in the lab.

TEKS 7.9B; partial 7.9A, MS-ESS1-2 (solar-system portion) and MS-ESS1-3 (orbital-scale comparisons). Formal Kepler-law calculations are extensions. The compatible English teacher pack is 1.0.0 and is delivered separately outside this website. Native Spanish science-educator review is pending.
