# Punnett Squares 1.1.1

High School Biology, grades 9–10. Original Sciesmic learning model and bilingual interface. Reuses nine PNGs from the existing Sciesmic Punnett Squares sprite pack v1, kit 1.13 (November 5, 2026). The 2×2 and 4×4 boards use semantic interactive page elements so each cell can be reached by keyboard. No new raster art was generated.

The DOM-free model uses equal segregation paths and independent fertilization. The two pea genes assort independently; linked genes are outside the model. Incomplete dominance preserves distinct R and W alleles (compact notation for Cᴿ and Cᵂ). Rendering and motion preferences never draw random numbers. Seed plus settings reproduces the offspring sequence, and samples at larger n extend the same seed's prefix.

The shell, motion clock, graph tools and glossary print/export renderer come unchanged from repository baseline eb24e05dee54d269bf040ab473e44cb57fb2b279. Use this baseline's kit when integrating; do not copy the lab into an older website export without reconciling dependencies.

Partial standards connections: TEKS Biology B.8B and NGSS HS-LS3-3. Environmental expression, linkage, mutation, selection, codominance, sex linkage and multiple alleles require other instruction. Sources are linked in content.js and Model notes.

Student work is saved locally in this browser on this site when browser storage is available. Reloaded partial samples resume paused. Use Export lab notebook for a printable offline HTML copy containing writing, practice, check responses and retained evidence; this export is a record, not an importable save file. Browser clearing/private sessions and a different site/device can lose saved work. Start fresh asks before clearing this lab’s saved work. Six recent completed trials are retained per mode; the three introductory families are also retained separately. Teacher resources point to the members library. No teacher pack content is included here.

Version 1.1.1 includes three four-offspring families before larger samples, optional Challenge practice with covered gamete headers and a required written cell explanation, evidence and a claim before mystery reveal, per-seed mystery claims, and graph zoom (auto/4/16/100/1000). Written explanations are recorded for teacher review, not automatically graded for scientific accuracy. Zoom and filtering preserve evidence; the y-axis remains 0–1. The science model remains version 1.0.0, unchanged.
