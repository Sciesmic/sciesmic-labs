# Earth & Moon 1.0.0

Free grades 6–8 simulation: lunar phases and eclipses, with synchronized space and Earth-observer views, northern/southern orientation, continuous phases, controllable tilt and node alignment, distance comparison, seeded prediction challenges, EN/ES, evidence tables/CSV and public vocabulary tools.

Run over HTTP from the parent site root; open earth-moon/?lang=en. Published at https://labs.sciesmic.com/earth-moon/. Spanish simulation and flashcards remain draft pending native science-educator review. Uses supplied Sciesmic Solar System v1.1 PNG art; overlays and paths represent model geometry.

TEKS 6–8.1G model practice with student drawing/revision; 7.9A Moon movement partial. NGSS MS-ESS1-1 partial: phases and eclipses, no seasons. Eclipse output uses an ideal Earth-center sightline and simple shadow cones; it is not an eclipse visibility forecast. See in-lab model notes for limitations. Private teacher pack 1.0.0 is kept outside the public site.
